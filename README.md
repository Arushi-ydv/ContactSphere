# ContactSphere

A full-stack Contact Management Web Application built using Spring Boot.

## Features

- User Registration and Login
- Secure Authentication and Authorization
- Email Verification
- Password Management
- Add, Update, Delete and View Contacts
- Contact Profile Image Upload using Cloudinary
- Send Email with Attachments
- Export Contacts to Excel
- Export Contacts to PDF
- Pagination
- User Profile Management
- Feedback System

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate

### Database
- MySQL

### Frontend
- HTML
- Tailwind CSS
- JavaScript
- Thymeleaf

### Other Tools
- Maven
- Cloudinary
- Git
- GitHub

## How to Run the Project

1. Clone the repository.
2. Create a MySQL database.
3. Configure the required values in `application.properties`.
4. Run the Spring Boot application.
5. Open the application in your browser.

## Security

Sensitive credentials are not included in this repository.

Use `application.properties.example` as a reference for configuration.
